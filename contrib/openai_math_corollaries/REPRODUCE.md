# Reproducing the compiles

This contribution is compiled against upstream's own pinned project, not with a lakefile of its own (none is shipped,
because none was tested). The driver is `scripts/lean_pinned.py`, which:

1. takes `LEAN_PATH` from `lake env` inside an openai/math checkout at commit `adc7f124` (`lean/` directory, toolchain
   `leanprover/lean4:v4.34.1`, Mathlib `d13f23b7` as pinned by upstream's `lake-manifest.json`);
2. prepends an output directory for this contribution's own `.olean` files;
3. runs `lean -DautoImplicit=false <file> [-o <olean>]`.

The paths at the top of `lean_pinned.py` (`PINNED`, `TOOLCHAIN_BIN`) are those of the producing machine; edit them.

```sh
# in the openai/math checkout (lean/): build the modules the Triangular files import
lake build OAI.Analysis.Triangular.Energy.Universal OAI.NumberTheory.DirichletL.LatticeSummability
# from the directory that contains lean/Triangular and lean/BAOCert:
python3 scripts/lean_pinned.py compile lean/Triangular/Riesz.lean --olean Triangular.Riesz
python3 scripts/lean_pinned.py compile lean/Triangular/RieszFinite.lean --olean Triangular.RieszFinite
python3 scripts/lean_pinned.py compile lean/Triangular/AnyDensity.lean --olean Triangular.AnyDensity
python3 scripts/lean_pinned.py compile lean/Triangular/Controls.lean --olean Triangular.Controls
python3 scripts/lean_pinned.py compile lean/Triangular/Axioms.lean   # prints the axiom audit
```

The BAOCert modules follow the same pattern; `scripts/compile_modules.py` and `scripts/compile_p2_tables.py` give
the order (the table modules are generated by `scripts/emit_*.py` from the DESI DR2 data and are shipped as generated).
Expected: exit code 0 and `#print axioms` ⊆ {propext, Classical.choice, Quot.sound}, except the two planted controls.
Recorded outputs: `audit/triangular/D1/compile_Axioms.json`, `audit/certified_numerics/*/compile_*.json`.
